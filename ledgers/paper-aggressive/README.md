# TITAN_AGGRESSIVE_LAB Ledger

This directory is exclusively for paper-only aggressive experiments under
strategy `TITAN_AGGRESSIVE_LAB`. It has no live order authority. Its records,
configuration, metrics, and strategy IDs must never be merged with live equity
or live options statistics.

Experiments may include 0DTE, sub-$5, far-OTM, halt-resumption, extreme
opening-range, low-float, and retail/social hypotheses. An observation here is
not a production rule and cannot authorize a live trade.
