# Paper Ledger

Create one immutable row per event in `YYYY-MM.csv`. Suggested columns:

`timestamp_et,trade_id,symbol,event,side,quantity,order_type,planned_price,fill_price,stop,target,fees_slippage,pnl,score,prediction_rank,setup_version,rule_deviation,evidence_link`

Paper fills must reflect observable liquidity and realistic slippage.
