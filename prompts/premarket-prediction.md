# Premarket Top 5 Prompt

Using the validated shortlist, publish exactly five ranked predictions before the opening bell.

For each: ticker, direction/setup, total and component scores, current price and volume with timestamps, thesis, catalyst/context, key levels, entry trigger, invalidation, expected path, time horizon, risks, and data caveats.

Save to `predictions/daily/YYYY-MM-DD.md` using the template. Freeze the record at publication. Later corrections must be appended with a timestamp and must not alter the original prediction.
