# Promoted Edges

Only explicitly reviewed, versioned rules with positive after-cost expectancy,
survivable drawdown, repeatability, acceptable execution, documented failures,
and out-of-sample evidence across multiple regimes belong here.

Maturity guidance is exploratory below 30 observations, developing from
30–99, provisional from 100–199, and promotion-candidate only at 200+ across
multiple regimes. Sample size alone never promotes a rule. Daily research has
read-only access and cannot mutate this directory.
